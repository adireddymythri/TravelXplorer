# TravelXplorer Frontend

React SPA for the TravelXplorer tourism platform.

## Structure

```
src/
├── components/     # Reusable components (Card, Navbar, Map, etc.)
├── pages/          # Route pages (Home, Destinations, PlaceDetail, etc.)
├── services/       # API service layer (api.js)
├── context/        # AuthContext, LanguageContext
├── hooks/          # useAuth, useFavorites
├── utils/          # constants, helpers
└── assets/         # Images
```

## Run

```bash
npm install
npm run dev
```

Default: http://localhost:5173
